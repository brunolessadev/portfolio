Projeto em destaque · Java

MediaDashboard

Uma biblioteca de mídias locais, organizada em um só lugar.

Aplicativo desktop para navegar por pastas e categorias, guardar favoritos e acompanhar episódios assistidos. Desenvolvido com Java 17 e interface em JavaFX.

  • Java 17
  • JavaFX
  • Maven
  • Gson / JSON
Explorar código e instruções ↗

O que implementei

  • 01

    Navegação por diretórios

    Leitura da biblioteca local e organização das mídias por categorias e pastas.

  • 02

    Preferências persistentes

    Favoritos, tema e estado dos episódios armazenados em JSON com Gson.

  • 03

    Interface e interação

    Eventos em JavaFX, visualização de fotos e temas personalizáveis.

Como o projeto está organizado

Classes com responsabilidades específicas para descobrir mídias, persistir configurações e construir a interface. O Maven gerencia as dependências e a execução. O projeto segue em evolução.
